## 部署到 GitHub Pages

1. 將 `index_zh.html` 改名為 `index.html`，放在 repo 根目錄
2. GitHub Repo → Settings → Pages → Source 選擇分支 → Save
3. 幾分鐘後透過 `https://<帳號>.github.io/<repo>/` 存取
